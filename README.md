# Smart Expense Tracker

A simple and interactive web application that helps users track their daily income and expenses. This project was created as part of my Web Development Internship at ApexPlanet.

## 📌 Project Overview
The Smart Expense Tracker allows users to add income and expenses, calculate their remaining balance, and visualize spending using charts. The goal of this project is to practice frontend development and build a clean and responsive user interface.

## 🚀 Features
• Add income and expense transactions  
• Automatically calculate total balance  
• Display expense data using charts  
• Simple and user-friendly interface  
• Responsive design for different screens  

## 🛠 Technologies Used

CSS

Chart.js
